# Source notes

The agent defaults to the following public sources:

1. Brønnøysund Register Centre Open Data — Central Coordinating Register (Enhetsregisteret): entity lookup and roles.
2. Brønnøysund Register Centre Register of Accounts (Regnskapsregisteret): annual-account copies as PDFs.
3. Company-owned website discovered from the official registry's `hjemmeside` field.

Official API documentation: https://data.brreg.no/enhetsregisteret/api/dokumentasjon/en/index.html
Official company data page: https://www.brreg.no/bruke-data-fra-bronnoysundregistrene/datasett-og-api/data-om-virksomheter/
Official annual-account API UI: https://data.brreg.no/regnskapsregisteret/regnskap/swagger-ui/swagger-ui/index.html?urls.primaryName=aarsregnskap
